Supporting documentation and examples for the Pulse engine.

Groupers](films/09-groupers/) · [10. Aggregators](films/10-aggregators/) · [11. Windows](films/11-windows/)
  3. **Analysis:** [12. Tests and regressions](films/12-tests/) · [13. Matrices](films/13-matrices/) · [14. SEM](films/14-sem/) · [15. Crosstabs](films/15-crosstabs/) · [16. Overlays](films/16-overlays/)
  4. **Beyond one request:** [17. Compose: batch and sweep](films/17-compose-sweep/) · [18. Compose: fit, bind and optimize](films/18-compose-fit/) · [19. Derived cohorts](films/19-derived/) · [20. Weights and raking](films/20-weights/) · [21. Time zones and panels](films/21-time/)
  5. **Around Pulse:** [22. Synthetic data](films/22-synth/) · [23. Embedding Pulse](films/23-embedding/)
