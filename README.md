# Pulse Casebook

Supporting documentation and examples for the Pulse engine.

- [`films/`](films/README.md): narrated films and media for outreach.
- [`showcase/`](showcase/): worked case studies showing how Pulse is used, each with its requests, data and reproduction steps.
- [`site/`](site/): the learning website, built from `films/` and `showcase/` (`make site-dev` to preview).
- [`studio/`](studio/README.md): Pulse Studio, a local visual builder for Pulse analyses kept in a library of workspaces (`make studio`, then `bin/studio ~/pulse-library`).
